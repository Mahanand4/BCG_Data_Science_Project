# BCG Data Science Project

## Project Overview

This project focuses on customer churn analysis and prediction using data science techniques.

The project includes data exploration, feature engineering, and machine learning modelling to understand customer behaviour and predict churn.

## Project Tasks

### Task 2 – Exploratory Data Analysis (EDA)
- Explored the dataset and analysed customer information.
- Performed data cleaning and exploratory analysis.
- Identified important patterns and relationships in the data.

### Task 3 – Feature Engineering
- Created and transformed features to improve the predictive power of the dataset.
- Prepared the cleaned data for machine learning.

### Task 4 – Modelling
- Split the dataset into training and testing sets.
- Built a Random Forest classification model.
- Evaluated the model using Accuracy, Precision, Recall and F1 Score.

## Files Included
- `Task 2 - eda_starter (2) (1) (2).ipynb` – Exploratory Data Analysis

## Model Evaluation

The Random Forest model was evaluated using:
